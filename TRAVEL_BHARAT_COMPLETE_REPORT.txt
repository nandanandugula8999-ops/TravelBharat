4. FEATURE-BY-FEATURE BEHAVIOR
------------------------------


4.1 Search (header)

- Index built by buildSearchIndex(): every state (label=name, sub=capital) + every place (label=name, sub="State - Category").
- Matching: trimmed, case-insensitive substring on label or sub; max 8 dropdown results; empty query closes dropdown; no-match shows escaped query + hint.
- Keyboard: [up]/[down] cycles (highlightMatch, aria-activedescendant), Enter opens highlighted (or single) result, Esc clears text first then closes. Click-outside closes. 120 ms debounce on input.
- Selecting a state -> openState(slug); a place -> openState then openPlace(slug, idx) after 60 ms. Input cleared after navigation.
- Search-clear (x) button appears while typing (.has-text), now keyboard-focusable.


4.2 Discover ("Find your destination")

- State: DISCOVER = { region, state, category, season, dtype, popular, sort } (all default all/recommended).
- Region + State dropdowns (state list now includes all 36, hidden suffixed "(UT / smaller state)"), Category (All/Heritage/Nature/Pilgrimage/Adventure), Best season (Any/Winter Oct-Mar/Summer Apr-Jun/Monsoon Jul-Sep, parsed from best month names with range expansion), Destination type (keyword-derived: forts/beach/sacred/water/hills/wildlife), Popular-only checkbox (membership in GALLERY slug|idx set), Sort (Recommended=insertion, Name, State, Category).
- Hidden states excluded unless explicitly chosen in the State dropdown.
- Active filters render as removable pills (clearDiscoverKey); count line reads "N places across M states" and matches the full filtered list; grid renders max 24 cards + "Showing 24 of N" note; empty state has a Reset all filters button.
- browseCategory(cat) resets the other five filters then sets category and smooth-scrolls to #discover; dropdowns stay in sync via syncDiscoverControls().


4.3 State view + category chips

- openState(slug) records home scroll, hides home sections, renders header/meta/count/tagline, chips (All places + present categories), itinerary banner, place list; unknown slug -> toast, no crash.
- setFilter(cat) re-renders; empty category shows "No places in this category yet" + Show-all button.


4.4 Place cards (state view + discover)

Media (lazy, async decode, sized) + category badge, category-state label, name, 3-line desc, meta table (Best time / Suggested duration / Entry), View-on-Map link (Google Maps search/?api=1&query=, rel="noopener noreferrer"), View details, + Add to trip (toggles to [done] Added), Book on MakeMyTrip (per-place mmtLink: holidays-india/<city>-travel-packages.html from map town with 7 aliases, e.g. Old Goa->goa, Havelock/Port Blair->andaman, Nongriat->meghalaya, Kurukshetra->haryana, Silvassa->daman, Himachal Pradesh->himachal; falls back to MMT homepage).


4.5 Destination modal

Image, category, title, state, desc + history, fact grid (Best time / Recommended duration / Timings / Entry fee / Location / State), generic Good-to-know tips (category-based + permit hint), button row (View on map, Book Your Trip when opened with booking context, Add-to-Wishlist toggle, Add-to-Trip toggle), up-to-3 Nearby-in-state, Close footer button. Overlay click, Esc, x all close; focus trap keeps Tab inside; focus returns to opener; nesting-safe scroll lock (lockScroll counter).


4.6 Wishlist

- wishlist: Set("slug|idx"), key travelbharat-wishlist; Array + string guards on load; stale keys (deleted data) pruned on render.
- Toggle from any card/modal/wishlist-row; all visible copies update without re-render (data-wish sync, focus preserved); header count + aria-label update with pop animation; toasts on add/remove.
- Panel: count meta, two-tap Clear all (3 s disarm), per-row View details / Add-to-trip / MakeMyTrip / Remove, empty state with Start-exploring CTA. No personal data stored.


4.7 Trip planner

- itinerary: Set("slug|idx") (insertion = user order), key travelbharat-itinerary; validated + pruned on load.
- Counts in state banner + plan section stay in sync; all Add-to-trip buttons sync via data-trip.
- Planner modal: empty state with CTA; otherwise Your N-Day Trip Plan + "N places - D days - S states - ~Hh planned" (hours are labeled estimates from category, never distances/prices). Pace selector Relaxed 2 / Classic 3 / Packed 4 per day (clamped 2-4); per-stop Morning/Afternoon/Evening/Late-evening slot labels; per-day ~hours; per-stop Maps link; [up]/[down] reorder (ends disabled), per-stop remove, two-tap Clear trip; Print (print CSS isolates the planner), Download (.txt itinerary), Share (navigator.share -> clipboard fallback -> unavailable message). Focus trap + focus restore + scroll lock.


4.8 Nav, FAQ, footer, toasts, theme, motion

- Desktop hover dropdowns + click toggle; mobile panel (max-height 100dvh?78px, scrollable); Esc/outside-click close; aria-expanded/aria-haspopup maintained.
- FAQ: 8 buttons (aria-expanded/aria-controls), smooth grid-rows accordion.

- Toasts: max 3, polite live region, auto-dismiss 2.6 s, dismiss button, safe-text injection.
